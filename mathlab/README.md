# Math/Lab — задания 02–05

8 задач, по 2 на каждую тему. Режим ученика, защищённый кабинет учителя, код класса, код продолжения, серверное сохранение, оценивание и CSV.

## Запуск

1. Создайте проект на https://supabase.com . В разделе SQL Editor выполните содержимое `setup.sql`.
2. В Supabase → Authentication → Providers включите Email. Для преподавателя зарегистрируйтесь через сайт и подтвердите email, если требуется.
3. В Supabase → Project Settings → API скопируйте **Project URL** и **anon/public key**. Никогда не используйте service_role key в браузере.
4. Откройте `index.html`, введите URL и публичный ключ. Преподаватель входит в кабинет, создаёт класс и выдаёт ученикам код класса.
5. Ученик начинает работу, записывает код продолжения и может возобновить сессию с другого устройства. Учитель видит отправленные и незавершённые ответы.

## GitHub Pages

Создайте публичный репозиторий на GitHub, загрузите `index.html` и `README.md`, в Settings → Pages → Deploy from a branch выберите main / root. После публикации GitHub выдаст адрес вида `https://USERNAME.github.io/REPOSITORY/`. **Сайт не опубликован автоматически**: требуется вход в ваш GitHub и настройка репозитория.

## Важно

- Общая база данных Supabase нужна даже при размещении HTML на GitHub Pages.
- Коды продолжения — секреты доступа к ученической сессии; не публикуйте их. Данные передаются по HTTPS на опубликованном сайте.
- Ключ Supabase anon публичный; права доступа обеспечивают RLS и серверные функции.
- Для реальных школьников необходимо определить политику хранения данных и получить необходимые согласия; лучше использовать псевдонимы, а не полные ФИО.
- Перед реальным запуском рекомендуется добавить rate limiting/CAPTCHA для публичных функций, поскольку анонимный ввод кода класса и кода сессии может подвергаться автоматизированным попыткам.
