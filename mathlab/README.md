# Math/Lab — домашняя работа по темам 02–05

Сайт содержит 8 задач по математике (по 2 на каждую тему). Ученики вводят имя и код класса, получают секретный код продолжения и могут восстановить работу с другого устройства. Ответы сохраняются в Supabase автоматически, преподаватель видит классы, ответы, статусы, оценки и может экспортировать CSV.

## Состояние подключения

- Supabase URL и **публичный** publishable key уже настроены в `index.html`.
- SQL-миграция `setup.sql` уже применена к проекту `eslvavrbljoceomjyyhf`; повторно выполнять её не требуется.
- Для входа преподавателя используется Supabase Auth (Email + пароль). Зарегистрируйтесь на сайте; при включённом подтверждении email перейдите по ссылке из письма.
- В кабинете преподавателя создайте класс и выдайте ученику его 8-символьный код.
- Ученику необходимо сохранить 24-символьный код продолжения. Обладатель этого кода может читать и изменять ответы до завершения.

## Защита

- Service role key в браузере отсутствует. Publishable key публичен по назначению.
- Доступ преподавателя ограничен собственными классами с помощью RLS.
- Ученические коды случайные, в БД хранится только SHA-256 хеш.
- Проверка баллов выполняется в PostgreSQL.
- Для работы с детьми используйте псевдонимы вместо полных имён и определите порядок обработки персональных данных.
- Перед широким публичным запуском рекомендуется добавить ограничение частоты запросов к RPC и антибот-защиту.
